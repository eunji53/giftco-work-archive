# Frontend Learning

giftco 사내 SSOT Data Platform의 주문 프로세스 상태 머신 뷰어(order-process-shipping-fee)를 F12로 분석한 것이 계기가 되어 시작한 프론트엔드 학습 프로젝트입니다.

- 시작: 2026-08-03 주
- 목표: React + TypeScript + Tailwind CSS + shadcn/ui + React Flow 조합으로, SSOT Viewer와 비슷한 "노드/엣지 다이어그램 뷰어"를 직접 만들어보기
- 배경: 데이터 분석/이커머스 실무 경험은 있으나 프론트엔드는 처음. 기본 개념만 익히고 나머지는 AI 코딩 도구와 협업하는 방식으로 진행
